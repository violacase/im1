# mijn-blog

Vue 3 applicatie: mijn-blog met Tailwind CSS v4 en shadcn-vue componenten.

## ✨ Features

- **Vue 3** - Laatste versie met Composition API
- **TypeScript** - Volledige type safety
- **Tailwind CSS v4** - Zero-config CSS framework
- **shadcn-vue** - Copy-paste componenten
- **Vue Router** - Client-side routing
- **ESLint + Prettier** - Code quality en formatting
- **Vite** - Snelle development server

## 🚀 Quick Start

```sh
# Installeer dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173
```

## 📁 Project Structuur

```
src/
├── components/ui/     # shadcn-vue componenten
├── views/            # Route pagina's
├── router/           # Vue Router configuratie
├── lib/              # Utility functies
└── style.css         # Globale styles
```
